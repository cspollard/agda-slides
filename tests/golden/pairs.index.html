Scaling Amortized Inference to Large Sets

Antoine Wehenkel · Michael Kagan · Lukas Heinrich · Chris Pollard

arXiv:2605.07972 · abstract

The paper in one line: train a mean-pool Deep Set on sets of at most two elements, then finetune the inference head on cached aggregates.

Inference from a set of observations

  • a target \(\theta\), say a signal fraction
  • a nuisance \(\psi\) shared by every observation
  • marginalising \(\psi\) couples the xᵢ
\[ p\left(\theta, X\right) = p\left(\theta\right)\, \int_{\Psi}^{} p\left(\psi\right)\, \prod_{i = 1}^{N} p\left({x}_{i} \mid \theta, \psi\right)\, \,\mathrm{d}\psi \]

Goal: one amortized \(q\left(\theta \mid X\right)\) for any set size \(N\)

The posterior does not factorise over observations because they share the nuisance parameter.

A bump hunt, event by event

  • signal fraction \(\theta\) in [0, 1]
  • signal location \(\psi\) unknown

At N = 100 the PAIRS posterior width tracks MCMC on the full set; the naive product of per-event posteriors is underconfident.

Two ways to scale, both costly

Combine per-observation posteriors

✓ scales to any set size

✗ misses what the observations share through \(\psi\)

Encode the whole set at deployment size

✓ principled: the set is seen jointly

✗ per step, memory grows as \(O\left(B\, {N}_{\text{max}}\right)\) and compute with the mean set size

Can we train small, and still deploy on sets of thousands?

Building blocks: NPE with a Deep Set

\[ {T}_{\omega}\left(X\right) = \frac{1}{N}\, \sum_{i = 1}^{N} {t}_{\omega}\left({x}_{i}\right) \]
\[ {\mathbb{E}}_{\theta, X}\, \log\left({q}_{\phi}\left(\theta \mid {T}_{\omega}\left(X\right)\right)\right) \]
t_omega is applied to each element; the mean-pooled embedding and N go to the head, a normalising flow or flow-matching model.

PAIRS: train on pairs, finetune on aggregates

Pretraining Aggregators for Inference at aRbitrary Set-sizes

Training memory and compute no longer depend on the largest set size.

Why two is enough

Theorem (informally)

If a mean-pooled statistic is sufficient at every \(N\), a network trained to be sufficient at \(N \in \{1, 2\}\) is sufficient at every \(N\), and the two statistics differ by an affine map.

At N = 2 the constraint is the additive equation \(g\left({y}_{1}\right) + g\left({y}_{2}\right) = h\left({y}_{1} + {y}_{2}\right)\). Mean-pool sufficiency holds exactly when the marginals are an exponential family; errors in pair training degrade gracefully.

Does it work? Five test beds

Bivariate Gaussian: trained at N ≤ 2, PAIRS tracks the analytic posterior up to N = 10⁵.

Circle Radius

Radius of a circle in 64×64 images with distractors; N up to 1000.

Digit Expectation

Expected digit from rotated MNIST images sharing one angle; N up to 1000.

3D Object Properties

Volume and aspect ratio from partial ModelNet40 views.

Molecular Lipophilicity

logP from sets of GEOM 3D conformers.

Baselines: N = 1, N = 1–10, a Gaussian head, and end-to-end at N = 1000 (synthetic tasks). Three seeds.

Results

  • PAIRS matches or beats every baseline on nearly all tasks
  • improves monotonically with N, though pretrained only at N ≤ 2
  • pretraining at N = 1–10 wins on Circle Radius, at 3–4× the cost
  • N = 1 falls behind where nuisance coupling matters

Cost and scale

Novel-view synthesis: three coloured spheres, a flow-matching head, one model for N from 1 to 100.

Take-aways

  • train small, deploy large
  • pairs recover the pooled representation, up to an affine map
  • training cost decouples from the deployment set size
  • open: max and attention pooling; the exponential-family idealisation
